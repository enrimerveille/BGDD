# BGDD 0.7.5 — Des boutons mieux intégrés

- Un bouton B facultatif sur YouTube, à gauche des actions de la vidéo, pour télécharger dans le dernier format choisi. Activé pour les nouvelles installations, il reste à votre choix lors d’une mise à jour.
- Des boutons YouTube et X aux couleurs de leur site, en thème clair comme sombre.
- Les pages Instagram et TikTok retrouvent leur interface sans commandes ajoutées ; téléchargements et carrousels restent accessibles dans BGDD.
- Disponible pour les Mac Apple Silicon et Intel, avec le popup et les raccourcis habituels.
