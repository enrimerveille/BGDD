# BGDD 0.7.1 — Une utilisation plus simple

- Audio original privilégie M4A sans réencodage, avec un autre format source si nécessaire.
- Les commandes de pause et de reprise rejoignent la file en attente ; les résultats gardent leurs fichiers et leur accès au Finder.
- Nouveau raccourci Chrome « Télécharger avec BGDD » : une vidéo unique, dans votre dernier format choisi. BGDD s’ouvre lorsqu’un choix est nécessaire.
- Notifications facultatives plus claires, silencieuses et sans titre de vidéo.
- Téléchargements macOS ARM et Intel. La création d’un autre format depuis un fichier local est retirée ; les anciens exports sont conservés.
