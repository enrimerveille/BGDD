# BGDD 0.7.9 — Diaporamas complets et raccourci TikTok

- Les diaporamas affichent toutes les images, même lorsque la musique est courte, et reprennent leur parcours si elle continue. Une image seule reste affichée pendant toute la musique.
- Après défilement dans TikTok, le raccourci télécharge directement la vidéo affichée dans le dernier format choisi.
- La page principale gagne des espacements plus réguliers, en clair comme en sombre. L’aide aux formats a été actualisée et les réglages simplifiés.
- Disponible pour les Mac Apple Silicon et Intel. Sans musique accessible, la génération sans son demande toujours votre accord.
