# BGDD 0.7.0 — Plus de formats, moins de téléchargements

- Créez un autre format depuis un résultat local, en conservant l’original. BGDD signale aussi les fichiers déjà enregistrés.
- Audio original conserve la piste accessible sans réencodage ; une synthèse distingue la source, la sortie prévue et le résultat vérifié.
- Mettez la file en pause ou reprenez un site temporairement limité, sans bloquer les autres plateformes.
- Ouvrez BGDD avec un raccourci Chrome personnalisable et activez, si vous le souhaitez, les notifications de fin de série.
- Téléchargements macOS ARM et Intel. Le réexport sécurisé concerne les fichiers enregistrés à partir de cette version. Sur Intel, la conversion H.265 reste SDR 8 bits ; la copie H.265 Main/Main 10 compatible est conservée.
