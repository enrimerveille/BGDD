# BGDD 0.7.8 — Des carrousels au rythme de leur musique

- Les vidéos photo suivent la durée de la musique disponible, avec toutes les images dans leur ordre et des transitions horizontales fluides.
- La récupération des images essaie les autres liens originaux disponibles lorsqu’une réponse ne peut pas être vérifiée ; les erreurs précisent mieux l’image concernée.
- Le raccourci TikTok reconnaît les lecteurs dont le cadre interne est invisible ; son diagnostic est accessible dans les réglages.
- Disponible pour les Mac Apple Silicon et Intel. Sans musique accessible, la génération sans son reste soumise à votre accord.
