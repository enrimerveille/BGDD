# Licences et inventaires

Les [notices actuelles](https://github.com/enrimerveille/BGDD/blob/main/THIRD-PARTY-NOTICES.md) et [l’inventaire documentaire](https://github.com/enrimerveille/BGDD/blob/main/licenses/DISTRIBUTION.json) décrivent les composants prévus par la documentation courante. Les fichiers `VERSIONS-arm64.json`, `VERSIONS-x86_64.json` et `SHA256SUMS` de la [release choisie](https://github.com/enrimerveille/BGDD/releases) restent la référence exacte de chaque paquet publié.

Les fichiers de licence GPL, LGPL, BSD, MIT, OFL et Unlicense sont conservés dans leur texte original. `CODEC-LICENSES.txt` rassemble les licences codec sans modifier leurs textes.

Les fichiers `DEPENDENCIES-rc2.json`, `REDISTRIBUTION-STATUS-050.json` et `UPSTREAM-LICENSE-LINKS.json` conservent les inventaires et analyses historiques de leur livraison ; ils ne décrivent pas à eux seuls les versions ou la qualification de la livraison actuelle. Les sources et notices de chaque release restent disponibles dans ses kits tiers.
